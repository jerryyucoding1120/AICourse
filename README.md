## 🎯 Project Overview & Deliverables
This repository contains the complete personal website portfolio and critical reflective analysis for the **AI Applications for Education** capstone project.

The portfolio investigates four generative AI modalities in educational contexts:

1. **AI-Generated Presentation:** Focus on **Kimi AI**, benchmarked against **Google Gemini** and **Gamma**.
2. **AI-Created Video:** Focus on **Google Flow / Google Vids**, benchmarked against **InVideo.io** and **HeyGen** (including exact timestamped pros/cons).
3. **AI Chatbot:** Focus on **Perplexity AI**, benchmarked against **ChatGPT (GPT-4o)** and **Replika** (evaluating citation verification vs. hallucination and classroom questioning dynamics).
4. **AI-Designed Images:** Custom AI-generated educational visuals featuring iterative prompt engineering logs (**Figure 1 vs. Figure 2**) and classroom scaffolding critique.
5. **Integrative Pedagogical Synthesis:** A comprehensive reflection addressing the teacher's role as curator, cognitive load theory, and preserving critical Socratic dialogue in an algorithmic classroom.

## 🚀 How to Deploy to GitHub Pages (Live in 60 Seconds)

1. **Push this repository to your GitHub account:**
   ```bash
   git init
   git add .
   git commit -m "Update portfolio: Clean academic presentation"
   git branch -M main
   git remote add origin https://github.com/<your-username>/ai-education-portfolio.git
   git push -u origin main
   ```

2. **Enable GitHub Pages:**
   * Go to your repository on [github.com](https://github.com).
   * Click **Settings** $\rightarrow$ **Pages** (under Code and automation in the left sidebar).
   * Under **Build and deployment** $\rightarrow$ **Branch**, select `main` and folder `/(root)`.
   * Click **Save**.

3. **Get Your Live URL:**
   * In 1–2 minutes, GitHub Pages will deploy your site to:
     `https://<your-username>.github.io/ai-education-portfolio/`
   * Copy this live URL and submit it to **e-Class** before **December 17th**!
